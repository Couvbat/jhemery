# Jules Hémery (Couvbat)

> Full-Stack Developer at In-Leed (France). Builds web apps, produces hard electronic
> music, and tinkers with AI on the side. This file is a machine-readable summary of
> https://jhemery.xyz for LLMs and agentic browsers — the live site is a client-rendered
> single-page app, so most of its content (and a hidden terminal easter egg) isn't
> visible to a fetcher that doesn't execute JavaScript.
